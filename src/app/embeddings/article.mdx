I saw a <a href="https://x.com/kieranklaassen/status/2103537214575743221">cool tweet </a> that proposed using Jev to generate a interpretable features about each data point (aka an embedding).

## The note as one vector

Jev scores are built to be read. text-embedding-3-large is not: it turns the whole note into one vector. These groups are k-means in that space, drawn with UMAP. They follow the kind of visit more than the sepsis syndromes above: children, pregnancy, heart disease, skin, and a lung infection group sit apart. The scores on a group are still Jev, which is how you can tell what the embedding picked up.
